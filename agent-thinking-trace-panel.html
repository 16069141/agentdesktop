数据协议（SSE Event）

面板消费两种事件，逐条 JSON 推送： 
// 类型1：深度思考
{ "event_type": "think",
  "content": "找到根因了。ShellTool.approval_callback 60s 超时后默认拒绝…" }

// 类型2：工具动作
{ "event_type": "tool_action",
  "status": "running",        // pending / running / done
  "content": "查找 create_tools 中 ShellTool 的实例化" }

接入真实 SSE

把模拟数据源换成真实连接即可，渲染逻辑无需改动： 
const es = new EventSource('/api/agent/trace?taskId=xxx');
es.onmessage = (e) => handleEvent(JSON.parse(e.data));
es.onerror   = () => es.close();

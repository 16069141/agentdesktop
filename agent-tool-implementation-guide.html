1

定义工具类 —— 让模型"认识"这个工具

agent/app/tools/__init__.py · BaseTool 基类
# 所有工具继承 BaseTool，只需实现 execute()
class BaseTool:
    name: str = "base"
    description: str = "Base tool"
    parameters = {"type": "object", "properties": {}, "required": []}

    async def execute(self, arguments): raise NotImplementedError

    def to_openai_schema(self):
        """转成 OpenAI function-calling 格式 → 随请求发给模型"""
        return {"type": "function", "function": {
            "name": self.name,          # 模型看到的名字
            "description": self.description,  # 模型据此决定何时调用
            "parameters": self.parameters, # 参数 JSON Schema
        }}

关键点：description 要写清"何时用、怎么用、别做什么"——模型就是靠它做决策的。

实现 doc_to_html 工具（Word→HTML，mammoth 引擎）

agent/app/tools/__init__.py · DocToHtmlTool.execute
# 工具执行核心：读 docx → mammoth 转换 → 返回 HTML
async def execute(self, arguments):
    path = arguments.get("path", "")
    if not path: return {"success": False, "error": "缺少 path"}
    p = Path(path)
    if not p.exists(): return {"success": False, "error": f"文件不存在: {path}"}

    import mammoth
    with p.open("rb") as fh:
        result = mammoth.convert_to_html(fh, style_map=[])  # 官方转换 API
    html = result.value
    return {"success": True, "html": html[:60000], "char_count": len(html)}

安装：pip install mammoth。返回的 HTML 会作为 tool_result 回填给模型，模型据此提炼、包装成完整页面。

Agent 编排循环 —— 让工具真正被调用（核心引擎）

agent/app/agents/orchestrator.py · run_stream()
# ① 把工具 schema 随请求发给模型
chat_kwargs = {"stream": True}
if tool_schemas and tools_enabled:
    chat_kwargs["tools"] = tool_schemas   # ← 模型因此知道可以调用工具

# ② 流式收集模型返回的 tool_calls
async for event in provider.chat(messages, model, **chat_kwargs):
    if event["type"] == "tool_calls":
        all_tool_calls += event["calls"]   # 模型说：我要调用 XX 工具，参数是…

# ③ 执行工具，把结果作为 role="tool" 消息回填
if all_tool_calls:
    tool_results = await self._tool_node.execute(all_tool_calls, ...)
    state.messages.extend(tool_results)      # ← 工具结果喂回给模型
    continue                              # ← 继续下一轮，直到模型给出最终答案

这就是多轮闭环：模型要工具 → 引擎执行 → 结果回填 → 模型继续，最多 10 轮，重复调用自动去重、连续 3 次同工具强制终止防死循环。

颤翎子 AI 助手 × 豆包 能力对标评测

评测基准：豆包（2026-09 功能全貌）｜对象：颤翎子 AI 助手（本地桌面客户端 v2，P0–P3 已上线）
成熟度评分为主观评估（0–100），用于示意差距方向，非官方度量。豆包信息来源见文末链接。
一句话结论：颤翎子在「智能体执行内核」上已达豆包 80% 水准（计划-执行-验证、多智能体、定时触发、技能市场都已闭环）， 但在「多模态产出层」和「生态层」差距最大——语音、图像/视频生成、在线办公套件、技能与连接器生态是缺失最明显的四大块； 同时在「本地优先 + 可审计安全 + 自有模型接入」上有豆包不具备的差异化优势。

3 · 颤翎子独有优势（豆包不具备）

本地优先 · 隐私自主

数据全落本机（SQLite + 本地文件），无云端留存；企业/敏感场景可直接部署，这是豆包云服务无法提供的卖点。

自有模型自由接入

任意 OpenAI 兼容模型可接入（当前 agnes / DeepSeek），不受豆包单一模型生态绑定；能力升级=换模型配置。

数据库直连 + 审计安全

db_query 直连只读业务库做分析，RPA/Shell 有白名单与熔断，全链路工具审计落库——面向企业的可解释、可追责。

4 · 补齐路线建议（按缺口 × 收益排序）

P0 · 最优先（2–4 周）

  • 语音交互：语音输入转文字 + 回答语音播报（系统 TTS/STT 即可起步），补"说话即用"
  • 图像生成工具：接入图像模型，把 generate_image 注册为工具，补齐创作闭环
  • 表格/图表生成：generate_xlsx + 数据图表渲染，追平 Office 三件套
  • 用户自定义智能体：复用 P3 引擎，让用户创建/保存/分享角色

P1 · 中期（1–2 月）

  • 在线可编辑产物：docx/xlsx/pptx 生成后客户端内预览编辑，替代"生成即死文件"
  • 应用搭建：generate_html 模板化 + 本地预览，向妙搭看齐
  • 技能生态运营：技能市场 8 → 50+，支持自定义技能上传与安装
  • 办公平台连接器：飞书/钉钉/企业微信 API 接入

P2 · 远期（3 月+）

  • 视频生成：接入视频模型（成本高，视模型成本再定）
  • 屏幕理解：截图问答 / 屏幕上下文（豆包手机助手已做）
  • 多端与云同步（可选）：权衡隐私卖点，做"本地优先+可选云同步"
